# W3 Lecture Exercise

1. Draw a UML diagram of the design.
   - Use any drawing tool you like! Pen and paper works well, as does https://app.diagrams.net/ - see the UML submenu for box and arrow templates.
   - Don't worry about making it pretty; the focus is on dependencies.
   - Include all internal dependencies. For external dependencies, include all behaviours that you consider relevant to the design.
   - Include other aspects (methods, attributes, constructors) that you consider relevant. But don’t get bogged down; they’re not the focus now.
   - Does the design follow HCLC and OCP? Can you identify any specific parts that are problematic? How does the UML diagram help us see them?

2. If you finish or get bored: look in the `mystery_box` subdirectory.
   - Can you figure out what this code does?
   - (Don’t spoil it for others if you figure it out)
